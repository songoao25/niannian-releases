# 念念 · 官方安装包下载

这里是「念念」的官方安装包下载仓，只放各平台的安装包和版本说明，**不含任何源码**。

念念是一款支持长期记忆的角色扮演创作工具。官网：https://nian.songsong.win

## 下载

到本仓的 **Releases** 页选择最新版本，按你用的设备下载对应的文件：

| 设备 | 文件 |
|---|---|
| Mac（Apple 芯片） | `Niannian-<版本>-mac-arm64.dmg` |
| Mac（Intel） | `Niannian-<版本>-mac-x64.dmg` |
| Windows | `Niannian-<版本>-win-x64.exe` |
| Android（13 及以上） | `Niannian-<版本>-android.apk` |

每个版本都会附带更新说明和各文件的 SHA-256 校验值，下载后可以对照校验文件是否完整。

已经装过念念的，应用内会自动提示新版本，也可以回到这里手动下载最新版覆盖安装，你的聊天和数据不会受影响。
